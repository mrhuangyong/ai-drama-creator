# 改编方法

## 拆到能写

每个主要事件明确：谁现在想要什么、阻力、为何此时行动、策略、对方回应、结果改变什么。“调查线索、感情升温、获得成长”不能替代具体过程。

合并人物时核对身份权限、信息来源、关系功能、时间地点能否兼容；不只因名字多就合并，不把多人贡献全塞给主角。可以补连接动作和对白；新增能力、证据、制度、亲缘、精确期限或解围资源会改变因果，要在改编说明记录。不能靠突然出现的援军或道具替人物完成最难的行动。

## 期待与兑现

开头选一件简单可懂、有情绪意义的异常、冲突、需求或决定。不强迫所有题材用猎奇、暧昧和误导开头。

| 钩子机制 | 使用条件与边界 |
| --- | --- |
| 悬念／信息差 | 已知事实引出具体未知；不故意藏去人物必知事实造假谜 |
| 冲突／危机 | 不同目标争夺结果；对手有动机和行动 |
| 反差／反转 | 已建立预期被新事实改变；有前因，不临时改规则 |
| 共鸣／身份代入 | 具体困境使观众关心人物；转成场景行为而非口播喊共鸣 |
| 视觉异常／结果前置 | 可见结果承载后续问题；时间线仍清晰 |
| 数字／收益 | 目标或代价本身有戏；不造统计、不硬塞营销话术 |

钩子可重叠，不需每集填十种。开头提出问题，衔接补必要信息和方向，正文行动推进并局部兑现，结尾带出值得看的后果。不机械每30秒反转，不以90秒后的内容可随意发挥作为原则。

时间、重量、距离分别关注何时发生、得失代价、空间／能力／关系／信息阻碍；按原著支持使用，不强加倒计时或借等待拖戏。

羁绊是推动或限制选择的牵挂，向导提供有来源的信息或方向，危机是必须回应的压力。它们是功能，可由同一人、事件或物件承担，不必另造三个角色；危机应有前因，不一写不下去就派陌生人威胁。

## 不同篇幅

短篇保一次完整情绪体验，可单集或少量连载；中长篇按阶段目标与不可逆转折组织。网文找其持续吸引读者的机制，合并重复验证，但不将温情、悬疑等一律改成打脸升级。

倒叙先给看点，仅补理解当下所需前情，其余在需要时揭示，不重演全部历史。悬疑关键线索和信息披露顺序须核对。

时长考虑实际读出对白／旁白、无对白动作、停顿与转场；同步声音动作不重复相加。无表演验证只给附假设的区间，不用统一字数承诺时长。

## 视觉化

心理描写优先外化为选择、行动、对白、物件和事件；确需主观信息可用简短心声。动作有对象和结果，不只堆皱眉、握拳、流泪。

景别决定范围，角度决定观看位置，风格决定呈现，运镜决定观看位置随时间变化。先明确信息，再选手段。景别有歧义时补腰部以上等边界；近景不等于必须虚化背景，平视不等于正面。

推拉是机位移动，变焦是焦距变化；摇镜是原地转向，横移是机位移动；环绕与绕镜头光轴旋转分清；慢动作是时间表现。固定镜头也能有强烈戏剧性。

大场面通过多个职责明确的镜头呈现，不依赖单镜多人混战、复杂接触或连续变形。替换拍法要保住事件因果和情绪后果。不凭未验证模型能力承诺生成成功率。

平台数据仅作待验证经验，不写成固定权重、三项达标稳赢或保爆公式。
