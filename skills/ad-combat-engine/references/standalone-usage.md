# 独立接收、连续性与规则优先级

## 直接接收材料

输入可以是小说片段、正式剧本、动作梗概、已有分镜或“帮我设计一场打戏”。直接提取角色、目标、冲突、地形、武器与结果；不用外部总控、导演卡、锁文件、其他技能或既有图像。只设计用户点名的动作场面，不接管整部剧。

用户没有给本次片段时长，也没有明确沿用已确认时长时，先询问“这次用15秒版还是30秒版？”在等待期间可读材料和整理动作，不擅自交付默认时长成稿。已给或明确沿用的时长不重复询问。用户要求两个版本则分别编排，不能只换总秒数。超过30秒的打斗按15秒／30秒连续拆段；总戏时长不等于每个生成片段时长，未定分段长度仍应询问。

默认沿用项目已有Seedance 2.5目标与画风；用户另指定模型或格式时服从该要求。这里的15／30秒是本技能的交付规格，资料中的平台上限、参考图数量和“官方规范”不作为实时产品规格保证。用户要求核实平台能力时另查官方来源。

只有风格未定且会实质影响动作媒介时，询问3D／2D／写实，同时继续动作提取。已有3D国漫风格不因资料中的手绘笔法改为水墨。

## 在当前材料内建立连续性

1. 角色：姓名、脸与衣装、伤势、惯用手、持物、能力上限；已有别名直接复用。只有文字也能写完整外观基准，不把“有图零外观”套到未提供图片的情况。
2. 空间：参照观察方向说明画左／画右、地标、地面高差、出入口、视线与攻防轴；位置变化必须由可见位移建立，反打不代表物理位置交换。
3. 作用链：起手／发力源→轨迹→命中或格挡／闪避→身体与环境反馈；镜头运动响应事件，不让摄影机凭空穿墙。
4. 累积：伤口、衣损、断剑、地裂和尘灰延续；断掉的物件不在下一镜自动复原。同一道具换手不新造一件。
5. 段缝：上一段末尾记录位置、朝向、持物、速度、伤势、天气与可见结果；下一段从这些状态接起。可自然硬切换机位，也可接动作，不强制末秒定格或白闪糊屏，不声称100%一致。
6. 图片引用：图N、[@角色]、@imageN只是用户已有编号或待绑定别名；未见图不声称已锁图，不编造已上传素材。人物参考板上的姓名文字不应进入成片字幕。

## 优先级与适用范围

当前用户要求与原文事件／人物能力／胜负／伤亡结果 → 已有项目视觉设定和交付格式 → 本文件及output-format.md的独立交付规则 → 按戏型选用本地动作库。资料中的旧编号只用于检索规则，不代表存在或执行了旧检查器。

库中“0.5秒硬撞”“必须三轮反杀”“双方同时挂彩”“敌潮单调增加”“武器只能变一次”“必须末帧定格”等是特定高燃模板的设计约束，不强改所有原文。必须保留已有强弱差和结果：碾压场面允许单方面挡招、威压或废去修为，不为双向攻防硬写强者受伤；逃脱、救人、缴械和不杀的胜利均可完成收束。

R1写实：重心、距离、惯性与可见接触反馈优先，不强加气爆、飞天、骨折或超能力。多人场按“来袭→处理主要威胁→重新建立下一威胁”的可读轮转，防背景敌人排队木立。详见physical-combat-basics.md。

R2商业武侠：力从脚、胯、躯干传至兵器；可借墙柱与地面制造反馈，放大程度服从人物能力。

R3玄幻：法宝／身体是术法来源；元素有外中内层材质、方向、尺度参照与命中结果。大场面与远程法术不套贴身时长下限；“有反馈”包括盾裂、位移、地面被压陷，不要求每次造成肉体伤口。3D使用立体材质，水墨／2D才取笔触规则。

## 自检与交付

默认直接用output-format.md案例格式输出可复制提示词。用户只问设计、分析或审稿时按请求回答，不强制成稿。只产文字，不运行图片／视频／音频生成，也不把资料中的“用户裁定”当作当前用户的授权。

本地脚本scripts/check_combat_prompt.py只检查时长、连续镜号、必要字段及部分工程标记。动作可行性、受力、角色能力、轴线、特效遮脸、胜负与原文一致性需要逐镜人工核对；不宣称旧C编号检测、成片质量或完播率已验证。严重冲突应修正稿件；创作节奏建议按戏型取舍，不为消告警把法阵强改成肉搏。
