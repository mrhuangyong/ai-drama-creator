# 冲击帧分级与战斗负面词库

> **来源**：吸收自用户提供的玄幻一镜到底参考稿。
> **定位**：本文件是 `combat-cheatsheet.md`（打戏速查库）的补充，管两件**全打戏通用**的事——**打击反馈分级**与**战斗段负面词库**。R3 玄幻的阵营色锁/Z型移位/群战递增/武器变形见 `epic-battlefield-protocols.md`（本文件不重复）。

---

## 一、冲击帧分级（Impact Frame Grading）

> **一句话：打击的"分量"要靠画面的冲击表现分级，让观众用眼睛"听懂"这一下有多重。**

| 级别 | 触发 | 表现 | 白闪 |
|---|---|---|---|
| **一级** | 普攻、普通命中、格挡 | 单帧硬直 / 局部火花 / 轻震屏 | 无 |
| **二级** | 技能命中、落地、多杀、破防 | 明显震屏 + 冲击波环 + 介质飞散（碎光/碎屑/烟尘） | 无 |
| **三级** | 大招爆发、终结技、全屏清场 | 强震屏 + 大面积冲击波 + 光爆 | **3 帧连续白闪** |

**三条规则**：

1. **分级 = 叙事权重**：一级是节拍（叙事里的"点"），二级是重音（"顿"），三级是爆点（"轰"）。**同一场戏里三级只给 1 次**（大招/终结技那一下），滥用即失效；
2. **白闪只属于三级**：一级/二级不要白闪（白闪是"过曝式冲击"，用多了廉价）；
3. **特写 + 冲击帧的绑定**：关键瞬间（如武器形态变化、终结技刺入）给**一帧近景特写 + 一级冲击帧**，把观众的注意力钉在那个细节上。

**写法（自然句，禁工程标记）**：
```
✅ "刀锋切入甲胄的瞬间，画面一震，碎光沿冲击环向外炸开"
❌ "★三级冲击帧 + 3帧白闪"（工程标记，模型不理解）
```

**与本地创作的关系**：冲击帧是 `standalone-usage.md`「镜头五要素」中"受力反馈"的增强；与 `core-combat-laws.md`「一镜一动一反馈」的"反馈"对齐——**每个动作都要有反馈，冲击帧是反馈强度的标尺**。

## 二、战斗段负面词库（Battle Banlist）

> **用法**：按镜把最易崩点改为正向可见动作；末尾负面只保留字幕、BGM、水印与必要的1—2条本场约束。已有旁白须保留，不默认禁旁白。格式依output-format.md。

### 2.1 节奏类（最致命）

```
开场前奏，环境空镜，建立镜，缓慢起手，蓄力铺垫，对峙观望，原地对峙，站桩打怪，
慢动作，升格，顿帧，冻结帧，卡顿，静止机位，匀速平推，0帧无动态，人物移出画面
```

### 2.2 剪辑类（一镜到底段）

```
硬切镜头，多机位剪辑，黑屏转场，空镜头，未杀完的定格，收势未完成，转身离开的背影
```

### 2.3 群体/规模类

```
场上只有三五只敌人，敌人数量越来越少，数量稀少，背景空荡，主角对着空气打，
敌人无反应，敌人无前摇
```

### 2.4 特效/受力类

```
特效漂浮无触发源，特效遮挡面部，特效无受力实体，
Z型轨迹断裂，音爆缺失
```

### 2.5 武器/形态类（有武器变形时）

```
单剑中途消失，双刀合并回单剑，强行三刀，凭空多出一把武器，副武器，
武器中途再变形，武器凭空换模，分化演出被省略
```

### 2.6 角色/肢体类

```
角色崩坏变形，肢体扭曲，多指，融图糊成一团，角色面瘫无表情，
畸形手部，多余手臂
```

### 2.7 色彩串色类（有阵营色锁时）

```
敌人被染成暖色/主角色，主角光效变成冷色/敌色，阵营色互串
```

### 2.8 平台合规类（通用，见 `standalone-usage.md`）

```
红色血液，伤口特写，断肢，血雾，怪物化为液体
```

### 2.9 画面瑕疵类（低关联，走否定式兜底即可）

```
UI界面，字幕，水印，背景音乐
```

> **栏目提醒**：负面仅写排除项，具体站位、光照和动作写入正向镜头；低关联瑕疵可用简短否定，高关联视觉概念优先换为正向描写。
