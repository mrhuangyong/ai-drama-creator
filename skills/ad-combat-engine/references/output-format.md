# 独立输出格式

默认使用本项目已采用的自然语言案例格式，每段一个swift代码块，分段标题在块外。按下面顺序填写：风格、场景、站位参考、实际发声角色的声音、逐镜自然句、负面。没有发声的角色不凭空加台词或配音栏。

- 风格明确时代、媒介、材质和光影；场景写地点别名、昼夜天气、固定地标与人物起始站位。
- `站位参考：@`在没有实际参考时只作为用户待绑定占位，不声称绑定成功；正文仍用自然语言说清站位。
- 角色声音写`角色名声音：@完整英文音色说明`；已有音色逐字沿用。无对白的纯打戏省略声音行，但动作音写进镜头。
- 镜头使用`镜头一：（3秒）景别、角度、运镜；谁从何处如何攻击，谁如何应对，命中后身体和环境怎样变化。`平均2—3秒，复杂节点可4秒，每镜只承载一个主要攻防任务及其即时反馈；整数秒合计精确等于已确认的15或30。
- 不把动作库招式名、协议字母、模式K、C编号、动力链编号或参数表当投喂内容。技术逻辑化成可见动作；已有原文招式名若是角色实际台词则保留台词，并展开可见效果。
- 用户指定一镜到底时保持一次连续拍摄，在镜头一中用连续整数秒区间写动作节点，不能写硬切／正反打。多镜版不因为使用2.5就强制一镜到底。
- 负面默认`不要bgm，不要字幕，字幕透明度为0%，不要文字水印`，按本场补1—2条最易崩点；有真实角色图时才加“角色形象严格参考已提供角色图”。不要一边保留原文画外音、一边默认禁止旁白。
- 用户明确要求连续时间轴正文时，改用0-3秒／3-6秒的连续时间流，不再并列一套镜头时长；两种格式只选一种。只有用户明确要求拆分正向／音效／负面时才拆三件套。

## 15秒纯动作示例

本例只示范格式，不是所有打斗必须复用的反杀或力量等级。

```swift
风格：架空修仙古风；3D国漫CG，UE5式电影光影；冷蓝冰雾与暗红火屑对照，金属和石面材质清楚。
场景：断桥[@断桥]；日/阴；桥面沿画面左右延伸，左端连山道，右端连石门，两侧低栏外是深谷；青衡[@青衡]白衣持银剑在画左，赤魈[@赤魈]黑衣持赤刃在画右，两人面向对方，石门留在赤魈身后。
站位参考：@
镜头一：（3秒）中全景，斜侧平视，向右跟移；赤魈由右端踏入桥心横斩，青衡向左退半步竖剑格挡，双刃擦出火花，受力双脚擦动桥面碎砂，赤刃仍朝画左压来。
镜头二：（3秒）中近景，过青衡肩侧拍，短促前推；青衡借格挡反力向左侧身，银剑沿赤刃外侧滑开，将刀锋带离胸前；赤魈顺势向前跨步收回赤刃，脚边石片被踩裂。
镜头三：（3秒）全景，桥栏内侧低机位，平行跟拍；赤魈蹬地再斩，暗红火屑贴刃向左卷出；青衡落脚稳住，以银剑挑开斩线，薄蓝冰屑和火屑在交击点炸散，桥栏表面留下一道缺口。
镜头四：（3秒）中景，斜前方平视，随剑短促转向；青衡转胯将银剑贴向赤刃护手，手腕一抖挑出赤魈的握持线；赤魈五指张开，赤刃朝右侧空桥面弹落，身体踉跄后退，刀落处溅起碎砂。
镜头五：（3秒）中近景，斜侧缓推；青衡向右逼近一步，银剑停在赤魈肩前，赤魈举起空手停步；桥面刀刃停止滑动，寒雾散开露出石门，两人衣摆仍随谷风摆动，胜负以缴械明确收束。
负面：不要bgm，不要字幕，字幕透明度为0%，不要文字水印，武器不凭空换形，人物不分身。
```
