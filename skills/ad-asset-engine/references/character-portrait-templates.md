# 人物四格设定图模板

## 先建身份，再建造型

直接从本次原文、用户清单和现有角色定义提取年龄、性别、脸型、肤色、发式、体型、身高比例、衣服与配饰。没有外部人物卡也可工作；欠缺信息标“推导／设计建议”，不伪称抄录已有锚点。年龄用有依据的范围；精确厘米不是必需，可用明确体型和头身比设计。

四格统一使用静态设定姿态。面部特写保持自然中性表情，头部摆正、平视、嘴唇自然闭合，不微笑、皱眉、张嘴或做手势。正面、90°侧面与背面三视图使用同一自然站姿，双脚自然落地，双臂自然下垂，双手空置。三视图不做叉腰、抱臂、行走或战斗等动作，不画手持、悬挂、背负或摆在身边的独立道具。服装和用于识别造型的穿戴配饰照常保留。

同一人换装、受伤、戴帽／脱帽要保留身份不变量，分别记录状态。帽子摘下后作为独立物件建道具，人物状态不再戴同一顶帽子；不是再创造另一顶。

## 外观与服装填写

人物外观基础六要素：年龄、性别、肤色、发型发色、五官辨识特征、服装。四格面部特写再完整填写五官10项：脸型骨相、眉形、眼型眼窝、瞳色反光、鼻梁山根、唇形唇色、下颌线、耳廓、标志性特征、面部肌肉与肤色。尊重人物年龄和媒介，不给儿童强加成人骨相或成熟皮肤。

服装八项：整体类型与层次、主辅配色、面料材质、纹样位置、领袖衣襟腰带等结构、整洁破损状态、鞋袜、造型专属配饰。职业人物补可见的服装标识、材质磨损与服装结构，避免只写一个职业名；独立箱包与武器另入道具，不为职业辨识强塞手持装备。

## 首套造型的交付结构

代码块外写角色身份、造型名称、图号或别名、来源和设计建议，先给两项声音文本：

**Voice Description（不进图）**：英文2—4句，含音高音质、语速、语调、情绪和配音用途；不声称已绑定TTS身份。

**Voice Description Label**：≤8个英文词，只概括核心音色，不使用长句。标签与完整描述都只保留在代码块外供配音交接，不进入图片。

图片上方预留居中标题区，只写实际角色名称。换装图仍写角色本名，例如“云若”，不写“云若·红嫁衣”、图号或素材别名。顶部标题区与底部细节条均不计入四格；整图仅有的两处文字＝顶部居中角色名＋图底音色速览标签（≤8词英文），视角名、图号、水印均不入图。提示词中的英文技术约束不是待渲染文字。

随后输出一个独立图像提示词代码块。下面是填写骨架，实际交稿全部替换为具体人物信息，不保留待填项：

```text
【角色四格设定图】
一位具体年龄范围、性别和身份的人物，整板16:9横版，全图共4格：面部特写、正面全身、90°侧面全身、背面全身。仅此四格，不设独立大主图，不重复视角，不增加第5格。
【顶部角色名】
画面正上方居中写着唯一文字：“云若”，绝对禁止输出任何其他英文字母、乱码或多余文字。
【人物身份】
写出肤色、头身比、体型、发型发色和标志性外观。写实人物可用6.5—7.5头身作为设计参考，3D／2D按已选风格与年龄另定，不将所有人物强制同一比例。
【五官10项锁定】
将脸型骨相、眉形、眼型眼窝、瞳色反光、鼻梁山根、唇形唇色、下颌线、耳廓、标志性特征、面部肌肉与肤色填成具体自然语言。眼睛须含眼部真实感描述：虹膜清晰纹理、瞳孔自然透光并带环境光反射光斑、眼白干净通透带细微血丝、睫毛根根分明、眼球曲面光影贴合、眼神自然有焦点；不写单独的“大眼睛、美瞳、长睫毛”。这些清晰五官仅在第一格渲染。
【服装与配饰】
完整写出本造型衣服八项，不混入其他造型。只含身上穿戴，不手持或摆放独立道具。
【四格内容】
第一格为面部特写，头部占该格高度约70%以上，是全图唯一清晰、可辨识的面部。头部摆正、视线平视、嘴唇自然闭合，保持中性表情，无头部动作、手势或剧情表演。
第二格为正面全身，第三格为90°侧面全身，第四格为背面全身。三格均头顶至鞋完整入画，头部完整保留、面部不刻画五官，使用featureless face, no facial features。三格使用同一端正站姿，双脚自然落地，双臂自然下垂，双手空置。无叉腰、抱臂或其他特殊动作，也无手持、悬挂、背负或摆放的独立道具。保持同一身形、服装和鞋袜，不裁头、不裁脚，不另画鞋手材质特写格。
【图底细节条】
四格下面设一条图底横向细节条：横向声纹波形或频谱图案（非文字图案，作为视觉一致性锚，不宣称能固定音频声线）＋图底音色速览标签——照抄图外Voice Description Label原文（≤8词英文），文字清晰正确、无乱码缺字变形。该细节条不是第五格，不占主视图区。
除顶部角色名与图底音色速览标签外，图中不得出现任何其他文字：不标图号、视角名或脸部处理，不加水印或额外字幕；完整Voice Description（2—4句长文本）不进图，仅图外交接给配音／TTS／下游。
【背景与光影】
纯白或用户指定的简洁背景，不混入剧情场景。布光柔和、五官可辨，材质与媒介一致。
【风格】
完整填入已选风格段。
negative prompt: extra fifth panel, different face, duplicate front view, repeated angle, second recognizable face, detailed facial features on body views, incomplete body, missing shoes, cropped framing, extra captions, gibberish, panel titles, watermark, logo, handheld props, dead black pupils, plastic eyeballs, dull lifeless stare
```

模板中的“云若”为示例；正式产出替换为当前实际角色名，不保留占位名。

“无脸”指只去五官细节，保留头型、发型、颈部与完整全身；不要在正文要求像素审查块、抹去头部或增加独立正面大图。角色板规则不能外推到允许标注的道具图和九宫格。

## 风格专属段

选择一项完整写入每条提示词：

- **3D**：3D国漫CG，UE5式电影光影，PBR材质与适度次表面散射，皮肤自然哑光；发丝、布料褶皱与饰物结构清楚，脸与身体采用一致的角色设计，非真人照片、非蜡像塑料。
- **2D**：二维动画，统一线条、色块与赛璐璐或已选厚涂方式，脸与身体同一画风；服装轮廓、鞋袜和配色清楚，不强加毛孔或三维渲染质感。
- **写实**：真人摄影质感，自然肤色与哑光皮肤；按年龄保留细小毛孔、绒毛、唇纹、眼周细纹和合理瑕疵，柔和光线下材质可辨；不机械给所有人去胡须、去痘印或美白，不改原著标记。

这些词是图像呈现要求，不代表已用某渲染引擎制作或验证效果。

## 换装与跨集延续

每个需要独立生成的造型一张四格板，关联同一角色身份。将首套脸型、五官、肤色、年龄、身形与音色完整复制到新条目，再写清本套衣服八项和配饰状态；不能只写“同图1／同上／与上一集相同”。

用户有参考图时，在代码块外说明应附哪张图和它只控制哪些不变量；没有图片时照样按文字基准继续。不得把实际参考图作为唯一来源而将衣服描述留空。

换装图仍只有四格，仍只一张清晰脸，仍头顶至鞋完整。为了保持每条可独立使用，完整英文Voice Description可原样复写或在同一文档的角色音色区完整保留，不能重新设计声音。每套板顶部居中写角色本名；图底细节条沿用首套的同一条波形设计与同一音色速览标签（每条提示词仍自包含，照抄同一标签原文渲染入图），不声称未见图片时已复制真实波形。用户后续明确要求某套纯图无字时按该项新要求覆盖，完整音色交接文本仍留图外。

## 自查

四格不多不少；面部锚点只有一处；三格全身均含头与鞋；头身比与人物年龄合理；特写表情中性且无动作，三视图姿态一致且空手无独立道具；顶部角色名和图底细节条不另占格；角色本名与图底音色速览标签是仅有的两处图中文字；完整英文音色留图外、≤8词短标签照抄渲染于图底；身份不变量与衣服状态不混写。检测文字约束不能冒充已查看生成图。
